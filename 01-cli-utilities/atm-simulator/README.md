# ATM Simulator

Interactive command-line ATM simulation supporting PIN validation, balance inquiries, cash withdrawals with overdraft protection, deposits, and transaction receipts.

---

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Concepts**: Loops, Conditional Logic, State Management, CLI Input Handling

---

## 🚀 How to Run
```bash
python atm_simulator.py
```

---

## 🌟 Key Features
- Secure 4-digit PIN authentication
- Real-time balance updates
- Insufficient balance validation
- Formatted transaction receipts
