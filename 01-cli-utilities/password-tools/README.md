# Password Security Tools

A suite of cybersecurity utilities for cryptographic password generation and entropy/strength evaluation.

---

## 📂 Included Utilities
1. **`password_generator.py`**: Generates customizable passwords with configurable length, special characters, uppercase, lowercase, and numeric digits using the `secrets`/`random` module.
2. **`password_strength_checker.py`**: Evaluates password resilience against dictionary rules, length thresholds, character diversity, and entropy scoring.

---

## 🚀 How to Run
```bash
# Generate secure password:
python password_generator.py

# Test password strength:
python password_strength_checker.py
```
