# Python Practice Projects

This repository contains a collection of small Python projects that I built while learning and practicing Python programming.

The projects focus on applying core programming concepts to simple problems. Each project helped me improve my understanding of Python syntax, program logic, functions, loops, conditional statements, and working with data.

## Projects

### Calculator

A basic command-line calculator that performs common arithmetic operations such as addition, subtraction, multiplication, and division.

### Student Record System

A simple program for managing student records. It allows users to add, view, search, update, and delete student information.

### Expense Tracker

A basic expense tracking program for recording daily expenses and viewing spending information.
